# Exam

## DoD

**[recruiter]** and **[interviewer]** can create an **[exam]** from a **[test]**, browse all their **[exam]** entries with details, and participants can join the live **[exam]** via link and password before the deadline.

### Exam Creation

1. **[recruiter]** and **[interviewer]** can create an **[exam]**.
2. Creating an **[exam]** requires picking a **[test]**.
3. During **[exam]** creation, **[recruiter]** and **[interviewer]** can use the default **[test]** setup or override the **[test]** setup.
4. An **[exam]** always requires a deadline.
5. During **[exam]** creation, **[recruiter]** and **[interviewer]** can specify when the **[exam]** closes.
6. During **[exam]** creation, **[recruiter]** and **[interviewer]** can specify attempt possibilities.

### Exam Participation

1. An **[exam]** is a real-time session based on a selected **[test]**.
2. Anyone, including **[anonymous]** visitors, can join an **[exam]** via link and password.
3. Participants can take the **[exam]** after joining.

### Exam Completion

1. After a participant finishes an **[exam]**, their **[exam_attempt]** is closed.

### Exam List

1. The application displays all **[exam]** entries for the signed-in **[interviewer]** or **[recruiter]**.
2. **[interviewer]** and **[recruiter]** can open the details view for each **[exam]**.

### Exam Statistics

1. The application displays **[exam_statistics]** for an **[exam]**.
2. **[recruiter]** and **[interviewer]** have full access to all **[exam_statistics]** displayed for an **[exam]**.
