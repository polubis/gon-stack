# General Requirements

## DoD

The application encrypts all platform data and maintains a fully anonymous **[anonymous_data_trail]** without real names.

### Data Encryption

1. The application supports full **[encrypted_data]** for all platform data.

### Anonymous Data Trail

1. The application maintains a fully anonymous **[anonymous_data_trail]**.
2. The **[anonymous_data_trail]** does not store real names.

### UI

1. The application UI supports viewport widths from 320px and above.
2. The application UI is fully accessible.

### Cookie And Policy Consent

1. The application asks for **[cookie_consent]** before tracking data.
2. The application tracks data only after **[cookie_consent]** is given.

### Compliance

1. The application is GDPR compliant.
2. The application is RODO compliant.

### Privacy Policy

1. A proper **[privacy_policy]** is attached in each place that requires it.
