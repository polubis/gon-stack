export const SIZES = ['s', 'm', 'l'];

# Button

Native `<button>`. Axes: `appearance` (`solid`), `color` (`primary`), `size` (`s | m | l`, default `m`), plus `type` (default `button`).

Hooks: `data-ds="button"`, `data-appearance`, `data-color`, `data-size`.

## Usage

```tsx
import { Button } from '@repo/uih/button';
```

```css
@import '@repo/uih/themes/aurora/index.css';
@import '@repo/uih/button/index.css';
```

```tsx
<Button.Root size="m">Save</Button.Root>
```

## Sizes

<div class="not-prose flex flex-wrap items-center gap-4" data-e2e="sizes">
  {SIZES.map((size) => (
    <Button.Root size={size} data-e2e={`size-${size}`}>
      Size {size}
    </Button.Root>
  ))}
</div>

## Disabled

<div class="not-prose flex flex-wrap items-center gap-4">
  {SIZES.map((size) => (
    <Button.Root size={size} disabled>
      Size {size}
    </Button.Root>
  ))}
</div>

## Scaling

The theme scales the whole page by device (see Responsive). For one dense area, wrap it in a theme scope and lower `--ds-density`:

```tsx
<div data-ds-theme style={{ '--ds-density': 0.8 }}>
  <Button.Root>Compact</Button.Root>
</div>
```

<div data-ds-theme class="not-prose flex flex-wrap items-center gap-4" style="--ds-density: 0.8" data-e2e="dense-buttons">
  {SIZES.map((size) => (
    <Button.Root size={size}>Dense {size}</Button.Root>
  ))}
</div>

## Override

Lowest tier first. Component token on any wrapper:

```css
.brand-zone {
  --ds-button-bg: #7c3aed;
  --ds-button-radius: 0.5rem;
}
```

Or a Tailwind class, no `!important` (hooks are `:where()`, specificity 0):

```tsx
<Button.Root className="rounded-md bg-emerald-600">Overridden</Button.Root>
```

<div class="not-prose flex flex-wrap gap-4">
  <Button.Root
    data-e2e="tailwind-override"
    className="rounded-md bg-emerald-600 bg-none"
  >
    Overridden
  </Button.Root>
</div>
