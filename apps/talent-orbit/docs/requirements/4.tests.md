# Tests

## DoD

**[recruiter]** and **[interviewer]** can create a **[test]** by linking **[question]** entries.

### Test Creation

1. **[recruiter]** and **[interviewer]** can create a **[test]**.
2. A **[test]** links **[question]** entries.
3. During **[test]** creation, **[recruiter]** and **[interviewer]** can specify the time for each linked **[question]**.
