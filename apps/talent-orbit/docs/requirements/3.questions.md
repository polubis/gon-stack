# Questions

## DoD

**[recruiter]** and **[interviewer]** can create **[question]** entries that always reference a **[concept]** from a **[knowledge_bank]**.

### Question Creation

1. **[recruiter]** and **[interviewer]** can create a **[question]**.
2. Every **[question]** must reference a **[concept]** from a **[knowledge_bank]**.
3. **[recruiter]** and **[interviewer]** must select a **[question_type]** during **[question]** creation.

### Concept Linkage

1. A **[concept]** acts like a memo describing an area of knowledge that should be covered.
2. A **[question]** is a specific question based on its linked **[concept]**.
