# Knowledge Bank

## DoD

**[recruiter]** and **[interviewer]** can create a **[knowledge_bank]** and organize **[concept]** nodes with metadata in a parent/graph structure.

### Knowledge Bank Creation

1. **[recruiter]** and **[interviewer]** can create a **[knowledge_bank]**.
2. A **[knowledge_bank]** acts as a directory for **[concept]** entries.

### Concept Management

1. **[recruiter]** and **[interviewer]** can create a **[concept]** inside a **[knowledge_bank]**.
2. A **[concept]** represents an area of knowledge that should be covered.
3. **[concept]** entries form a parent/graph structure within a **[knowledge_bank]**.
4. Each **[concept]** node has metadata.
