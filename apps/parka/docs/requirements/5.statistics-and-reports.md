# Statistics & Reports

## DoD

**[user]** can obtain **[statistics]** for selectable time ranges, compare spending between calendar months, and generate a **[monthly_report]**.

### Statistics

1. The application provides **[statistics]** for the signed-in **[user]**.
2. **[user]** can request **[statistics]** for a calendar month, three months, six months, or one year.
3. **[statistics]** include spending trends over the selected time range.
4. **[statistics]** include **[category]** breakdown expressed as percentages of total spending.

### Month Comparison

1. The application compares total spending for the current calendar month to the previous calendar month.
2. The comparison identifies the **[category]** entries with the largest spending change between the two months.
3. Each identified change includes the **[category]** name and the percentage difference.

### Monthly Report

1. The application can generate a **[monthly_report]** for a selected period.
2. A **[monthly_report]** includes total amount spent.
3. A **[monthly_report]** includes the count of distinct **[category]** entries used.
4. A **[monthly_report]** includes the count of **[recurring_expense]** transactions.
5. **[user]** can obtain the full **[monthly_report]** as a downloadable artifact.
