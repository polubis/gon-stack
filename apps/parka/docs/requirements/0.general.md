# General Requirements

## DoD

The application provides personal finance management with transparent AI, GDPR-compliant data handling, and cookie consent before tracking.

### Cookie And Policy Consent

1. The application asks for **[cookie_consent]** before tracking data.
2. The application tracks data only after **[cookie_consent]** is given.

### Compliance

1. The application is GDPR compliant.
2. The application is RODO compliant.
3. The application stores **[user]** data in the EU.
4. The application encrypts **[user]** data at rest and in transit.

### AI Transparency

1. The application discloses how **[ai_receipt_analysis]** works.
2. The application is AI Act friendly and does not use manipulative AI practices.

### Privacy Policy

1. A proper **[privacy_policy]** is available wherever data processing requires it.
