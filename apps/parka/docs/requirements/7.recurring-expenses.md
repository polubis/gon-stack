# Recurring Expenses

## DoD

**[user]** can define and manage **[recurring_expense]** entries, control whether each is actively tracked, and inspect its payment history.

### Recurring Expense Management

1. The application provides all **[recurring_expense]** entries belonging to the signed-in **[user]**.
2. Each **[recurring_expense]** includes a name, recurring cost, and next payment date.
3. **[user]** can enable or disable tracking for a **[recurring_expense]**.

### Recurring Expense Details

1. **[user]** can retrieve full details for a **[recurring_expense]**.
2. **[recurring_expense]** details include the associated **[payment_method]**.
3. **[recurring_expense]** details include payment history.
