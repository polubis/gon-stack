# Categories

## DoD

**[user]** can define and maintain **[category]** entries used to classify **[expense]** and **[receipt_item]** records.

### Category Retrieval

1. The application provides all **[category]** entries available to the signed-in **[user]**.

### Category Creation

1. **[user]** can create a **[category]**.
2. A **[category]** has a name.
3. A **[category]** has a distinguishing identifier chosen from a predefined set.

### Category Maintenance

1. **[user]** can update an existing **[category]**.
2. When updating a **[category]**, **[user]** can change its name or distinguishing identifier.
