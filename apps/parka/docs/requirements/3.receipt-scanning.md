# Receipt Scanning

## DoD

**[user]** can submit a **[receipt]** for AI processing, review and correct extracted **[receipt_item]** data, and persist the result as an **[expense]**.

### Receipt Submission

1. **[user]** can submit a **[receipt]** image for processing.

### AI Extraction

1. The application uses **[ai_receipt_analysis]** to extract data from a submitted **[receipt]**.
2. **[ai_receipt_analysis]** extracts the store name from a **[receipt]**.
3. **[ai_receipt_analysis]** extracts the purchase date from a **[receipt]**.
4. **[ai_receipt_analysis]** extracts a list of **[receipt_item]** entries from a **[receipt]**.
5. **[ai_receipt_analysis]** assigns a **[category]** to each extracted **[receipt_item]**.

### Receipt Review

1. After extraction, **[user]** can review the store name, purchase date, and list of **[receipt_item]** entries before persisting.
2. During review, each **[receipt_item]** includes its assigned **[category]**.

### Item Correction

1. **[user]** can correct a single **[receipt_item]** before persisting.
2. **[user]** can change the name of a **[receipt_item]**.
3. **[user]** can change the price of a **[receipt_item]**.
4. **[user]** can change the **[category]** of a **[receipt_item]**.
5. **[user]** can change the quantity of a **[receipt_item]**.
6. **[user]** can change the discount of a **[receipt_item]**.

### Persist Expense

1. **[user]** can confirm reviewed **[receipt]** data and persist it as an **[expense]**.
