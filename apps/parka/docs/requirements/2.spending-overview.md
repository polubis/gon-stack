# Spending Overview

## DoD

Signed-in **[user]** can inspect monthly spending totals, period-over-period change, and spending distribution, and initiate common finance operations for a selected calendar month.

### Monthly Spending Summary

1. The application provides the signed-in **[user]**'s total spending for a selected calendar month.
2. The application provides the percentage change in total spending compared to the previous calendar month.
3. The application provides spending distribution over the selected period.

### Month Selection

1. **[user]** can select which calendar month the spending overview applies to.

### Operations

1. **[user]** can initiate **[receipt]** submission from the spending overview context.
2. **[user]** can access **[spending_limit]** management from the spending overview context.
3. **[user]** can access **[recurring_expense]** management from the spending overview context.
