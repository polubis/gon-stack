# Limits & Goals

## DoD

**[user]** can define a total monthly **[spending_limit]**, define per-**[category]** limits with optional alerts, and track **[savings_goal]** progress.

### Total Budget

1. **[user]** can define a total monthly **[spending_limit]**.
2. The application tracks amount spent against the total **[spending_limit]** for the current calendar month.
3. The application provides spent amount, limit amount, and percentage consumed for the total **[spending_limit]**.

### Category Limits

1. **[user]** can define a **[spending_limit]** for a specific **[category]**.
2. The application tracks amount spent against each **[category]** **[spending_limit]** for the current calendar month.
3. The application provides spent amount, limit amount, and percentage consumed for each **[category]** **[spending_limit]**.

### Limit Alerts

1. **[user]** can define a new **[spending_limit]** for a **[category]**.
2. When defining a **[spending_limit]**, **[user]** can specify the limit amount.
3. When defining a **[spending_limit]**, **[user]** can enable an alert when 80% of the limit is consumed.
4. When defining a **[spending_limit]**, **[user]** can choose push or email delivery for limit alerts.

### Savings Goals

1. **[user]** can retrieve all active **[savings_goal]** entries.
2. **[user]** can create a **[savings_goal]** with a name, target amount, and timeline.
3. The application tracks amount saved against the target for each **[savings_goal]**.
