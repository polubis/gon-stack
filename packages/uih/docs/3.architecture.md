# Architecture

Contributor reads this page and knows where each file lives, what it may depend on, what is shipped as one unit.

## Terms

- **[theme_pack]** - folder of CSS under `themes/{name}`. Data only, no JS. e.g. `themes/aurora`
- **[core]** - pure TS shared by components. No React, no DOM, no CSS. e.g. `core/models.ts`
- **[component_folder]** - folder per component. e.g. `button/`
- **[entry]** - file consumer imports. e.g. `button/index.tsx`
- **[unit]** - smallest thing consumer imports alone. e.g. one [component_folder], one [theme_pack] file

## Layout

```
src/
  themes/
    aurora/                 default, only theme for now
      index.css             imports the files below in order
      reset.css             same code as Tailwind preflight
      tokens.css            tokens as defined by token hierarchy
      scale.css             --ds-scale steps + root font size
      animations.css        additional keyframes
      typography.css        type styles
  core/
    models.ts               shared types
    ...                     pure TS functions
  button/
    __tests__/              unit tests
    __e2e__/                e2e tests
    index.css               component styles
    index.tsx               component
  {component}/              same shape for every component
```

## Requirements

### Themes

- **THM-1** MUST keep each [theme_pack] self-contained under `themes/{name}/`. Adding a pack touches no component. `<pattern:themes/{name}/>`
- **THM-2** MUST keep [theme_pack] CSS only. No JS, no TSX.
- **THM-3** MUST name theme files by role, same set in every pack. `<files:reset.css, tokens.css, scale.css, animations.css, typography.css, index.css>`
  - 3A. `reset.css` holds Tailwind preflight code unchanged. Only the layer wrapper is added, on import. `<layer:ds.base>`
  - 3B. `tokens.css` holds tokens, in layer `ds.tokens`.
  - 3C. `animations.css` holds `@keyframes` and motion helpers only. No selectors tied to a component.
  - 3D. `typography.css` holds type styles on base elements and type tokens' consumers, in layer `ds.base`.
  - 3E. `index.css` imports in order: tokens, scale, reset, typography, animations.
  - 3F. `scale.css` holds `--ds-scale` steps as `min-width` queries in `rem` (layer `ds.tokens`) and the root font size rule `:where(html)` (layer `ds.base`). Nothing else. Importing it is optional.
- **THM-4** MUST ship each [theme_pack] file as its own [unit]. Consumer may import `tokens.css` without reset.
- **THM-5** MUST default to `aurora`. It is the only pack until a second is added.
- **THM-6** MUST NOT make a component import a [theme_pack]. Components read tokens by name only.

### Core

- **COR-1** MUST be pure TS. No React, DOM, CSS, or I/O. Verify: [core] runs in plain Node.
- **COR-2** MUST hold shared types in `core/models.ts`. Component-only types stay in the [component_folder].
- **COR-3** MUST keep functions in [core] pure, deterministic, side-effect free.
- **COR-4** MUST NOT import from any [component_folder] or [theme_pack]. Dependency points one way: component → core.
- **COR-5** MUST be tree-shakable. One exported function or type per concern, named exports, no barrel with side effects.

### Components

- **CMP-1** MUST put each component in its own [component_folder]. `<pattern:src/{component}/>`
- **CMP-2** MUST contain exactly: `index.tsx`, `index.css`, `__tests__/`, `__e2e__/`. More files only when the component needs them.
  - 2A. `index.tsx` is the [entry] and the only file consumer imports for JS.
  - 2B. `index.css` is the style file defined by component style rules. Imported by consumer, never by `index.tsx`.
- **CMP-3** MUST NOT import another [component_folder]'s internals. Reuse goes through [core] or the other component's [entry].
- **CMP-4** MUST NOT import CSS from TSX. Zero side effects on import.
- **CMP-5** MAY import [core]. MUST NOT import a [theme_pack].
- **CMP-6** MUST place tests by repo convention. Unit in `__tests__/`, e2e in `__e2e__/`, next to the code under test.

### Dependencies

- **DEP-1** MUST keep this direction only: `component → core`. `theme_pack` depends on nothing.
  ```
  button ──► core
  button ──► @repo/react-kit (subpath imports, components only)
  themes/aurora   (no edges)
  ```
- **DEP-2** MUST NOT create a cycle between [component_folder]s.
- **DEP-3** MUST keep React a peer dependency of components only. [core] and [theme_pack] have none.
- **DEP-4** MUST depend on `@repo/react-kit`, components only. It is the one internal runtime dependency. e.g. `@repo/react-kit/context`.
  - 4C. Component needing React utils (context, class names) uses react-kit. No local copies.
  - 4A. Import by subpath, never from a package root. Tree-shaking stays intact.
  - 4B. [core] and [theme_pack] MUST NOT import it.

### Entries and units

- **ENT-1** MUST expose one subpath per [unit]. `<pattern:uih/{component}, uih/{component}/index.css, uih/themes/{name}/{file}.css>`
- **ENT-2** MUST list CSS files as the only side-effectful files. JS has none.
- **ENT-3** MUST keep source layout and published layout identical. `src/button/index.tsx` → `dist/button/index.js`. No flattening, no renaming.
