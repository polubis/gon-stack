Lekcja 01: serwer i SSH

Po co: VPS to komputer w datacenter bez ekranu. Wszystko robisz zdalnie przez terminal. Bez tego nie postawisz Dockera ani Supabase.

Wygrana: logujesz sie na VPS i widzisz jego nazwe, system i uzytkownika.

Pojecia (5)

  • VPS - wirtualny serwer z wlasnym Linuxem i adresem IP.
  • Terminal - okno, w ktorym wpisujesz komendy tekstowe.
  • Shell - program czytajacy komendy (u Ciebie bash).
  • SSH - szyfrowane polaczenie z terminalem zdalnej maszyny.
  • root - superuzytkownik, moze wszystko, tez zepsuc wszystko.

Cwiczenie

  1. W panelu Hostinger (hPanel) wybierz system Ubuntu 24.04 LTS bez paneli (czysty Ubuntu). Zapisz IP i ustaw haslo root.
  2. Na swoim komputerze otworz terminal (Windows: PowerShell; Mac/Linux: Terminal).
  3. Polacz sie:
    ssh root@TWOJE_IP
    Przy pytaniu o fingerprint wpisz yes, potem haslo (nie widac znakow).
  4. Wpisz po kolei:
    whoami
hostname
cat /etc/os-release
pwd
  5. Wyloguj: exit.

Sprawdz sie (bez zagladania)

  1. Co zwrocilo whoami i dlaczego?
  2. Do czego sluzy fingerprint?
  3. Dlaczego root na stale to zly pomysl? (odpowiemy w lekcji 02)

Zrodlo: OpenSSH manual, na serwerze man ssh.
